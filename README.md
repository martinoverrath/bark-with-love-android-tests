# Bark with Love – Android-Testversion

Testversion der Android-App von [Bark with Love](https://barkwithlove.de). Diese Seite enthält nur die installierbare App-Datei, keinen Quellcode.

## Installieren

1. Öffne auf deinem Android-Handy den Bereich **[Releases](../../releases/latest)** und tippe auf **BarkWithLove-1.0.0.apk**.
2. Android fragt, ob du Apps aus dieser Quelle installieren darfst. Erlaube es einmalig für deinen Browser.
3. Tippe auf **Installieren**. Meldet Google Play Protect eine „unbekannte App“, tippe auf **Trotzdem installieren**. Das ist bei Testversionen normal.
4. Öffne **Bark with Love** und melde dich mit deiner E-Mail-Adresse an. Du bekommst einen Code per Mail.

Voraussetzung: Android 8 oder neuer.

## Was du testen kannst
Anmelden, Hundeakte und Notfallkarte, Erinnerungen, Spaziergänge aufzeichnen, Fotos aus der Galerie übernehmen. Käufe sind in dieser Testversion nicht möglich.
